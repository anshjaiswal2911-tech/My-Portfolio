3. Flagship Product Case Studies

Voice UX • Accessibility • Full-Stack AI
01. GramVoice AI — Voice-First Multimodal UI for Rural Bharat
🌐 Live Demo ↗ 💻 Source Code ↗
🔴 The User Pain Point

Over 70% of rural Indian micro-entrepreneurs lack English literacy and struggle with dense government loan portals (PM Mudra Yojana). Traditional forms create severe drop-offs and frustration.

🟢 The UX/UI Design Solution

Designed a zero-text, voice-driven interface. A pulsating 64px central microphone button invites spontaneous speech in Hindi/regional dialects, with real-time waveform animations confirming listening state.

UX Architecture & Usability Heuristics:

  • Multimodal Feedback: Audio waves + visual status pills give clear system state transparency (Nielsen Heuristic #1).
  • Bite-Sized Action Cards: AI responses are parsed into structured cards (Eligibility, Amount, Next Steps) to eliminate cognitive overload.
  • Tech Stack: React.js, Web Speech API, Google Gemini AI, Express.js, Tailwind CSS.

4. The "Aura Noir" Design System & Visual Architecture

The portfolio operates on a bespoke, modular design system engineered for high visual contrast, responsiveness, and consistent spatial rhythm:

🎨 Color Psychology & Contrast
  • Base Canvas: Deep Obsidian (#030712) for glare-free readability.
  • Primary Accent: Cyan Pulse (#22d3ee) for primary actions.
  • Depth Gradient: Indigo to Violet glow for atmospheric immersion.
  • Accessibility: 6.2:1 contrast ratio (exceeds WCAG 2.1 AA).
📐 Spatial Grid & Micro-Interactions
  • 8pt Baseline Grid: Consistent padding, margins, and component heights.
  • Physics Springs: Framer motion curves (stiffness: 300, damping: 20).
  • Sticky Scroll Deck: 3D depth perception with progressive scaling.
  • Touch-Safe: Minimum 48px touch targets for mobile.

5. Problem Solving & Performance Engineering

💡 Design Philosophy: "Performance IS User Experience"
A visually stunning interface is useless if it loads slowly or stutters on mobile. Below are the key engineering solutions implemented to uphold design fidelity:
⚡ 98.2% Asset Weight Optimization

Initial prototype was 8.5MB. Built an automated WebP pipeline with sharp:
• Logo: 980KB $\rightarrow$ 10KB
• Avatars: 3.4MB $\rightarrow$ 34KB
• Artwork: 1.7MB $\rightarrow$ 64KB
Total Payload: 157KB (10.6x faster load time).

🔒 Dual-Sync Zero-Loss Ingestion

Prevented form failure drop-offs with concurrent ingestion:
• Primary Store: Supabase PostgreSQL table with Row-Level Security.
• Instant Dispatch: Authenticated EmailJS alert webhook to Gmail inbox.
